# 🚌 Bus Ticket Management System

Welcome to the **Bus Ticket Management System** repository! This project is developed using **Core Java** and demonstrates the implementation of Object-Oriented Programming concepts to manage bus ticket booking operations efficiently.

---

## 📌 Project Overview

The Bus Ticket Management System is a console-based application that allows users to manage bus ticket reservations, passenger details, seat allocation, fare calculation, and ticket cancellations.

The project aims to simplify the ticket booking process while maintaining accurate passenger and travel records.

---

## 🚀 Features

* 🚌 Bus Management
* 👤 Passenger Registration
* 🎫 Ticket Booking
* 💺 Seat Allocation & Tracking
* 💰 Fare Calculation
* ❌ Ticket Cancellation
* 📋 Booking Details Management
* 🔍 Search Passenger Information
